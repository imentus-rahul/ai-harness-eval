# Evaluation output

Generated by `python3 -m eval` (live OpenRouter Haiku) or `python3 -m eval --dry-run` (mocks under `mocks/`).

| Path | Contents |
|------|----------|
| `good-harness-example/` | Baseline vs **good-candidate** — phase 1 POSITIVE, phase 2 runs |
| `bad-harness-example/` | Baseline vs **bad-candidate** — phase 1 NEGATIVE, phase 2 blocked |
| `summary.json` | Index of scenario runs (both scenarios when using `--dry-run` with `scenario: both`) |

Each example folder:

```
<example>/
  phase-1/baseline|candidate/trials/<task>/<rep>/...
  phase-1/comparison/result.json
  phase-2/...          # only when graduation + regression gates pass
  summary.json
  human_spot_check.md
```

Compare findings: `good-harness-example/phase-1/*/trials/auth-vs-log/0/result/findings.json`.

Legacy `output/phase-1/` and `output/phase-2/` are removed when a full dual dry-run runs.
